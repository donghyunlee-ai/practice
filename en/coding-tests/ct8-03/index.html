The page a post is on

Write code · Medium · §8.1 Searching a sorted list

posts holds the numbers of the posts still on a message board, in ascending order. The numbers of deleted posts are not in posts. The board list shows k posts per page in the order of posts: page 1 shows posts[0] to posts[k - 1], page 2 shows the next k, and so on.

links holds the numbers of posts reached through shared links. Complete the function solution, which returns a list of the page each linked post is on, in the same order as links. If a link's number is not in posts (the post was deleted or never existed), use -1 for that link.

Function

solution(posts, k, links)

Constraints

  • The length of posts is from 1 to 500,000.
  • The elements of posts are different integers from 1 to 1,000,000,000, in ascending order.
  • k is an integer from 1 to 100.
  • The length of links is from 1 to 20,000, and each element is an integer from 1 to 1,000,000,000.
