Friend triangles

Write code · Medium · §7.2 Permutations and combinations

There are n users on a social network, numbered from 0 to n - 1. A record [a, b] in friends means that a and b are friends with each other, and either number may be written first. Three people who are all friends with one another form a friend triangle.

Complete the function solution, which returns the number of friend triangles. The same three people count only once, whatever order you pick them in.

Function

solution(n, friends)

Constraints

  • n is an integer from 3 to 90.
  • The length of friends is from 1 to n * (n - 1) // 2.
  • Each element of friends has the form [a, b], where a and b are different integers from 0 to n - 1.
  • The same two people appear in at most one record.
