Write code · Basic · §8.1 Searching a sorted list

likes holds the number of likes on each of one person's posts, in ascending order. Several posts may have the same number of likes.

A "Popular" badge goes on posts whose likes reach a certain bar, and the candidate bars are collected in goals. Complete the function solution, which returns, for each bar in goals, the number of posts with at least that many likes, as a list in the same order as goals.

Function

solution(likes, goals)

Constraints

  • The length of likes is from 1 to 100,000, and its elements are in ascending order.
  • Each element of likes is an integer from 0 to 1,000,000,000.
  • The length of goals is from 1 to 10,000, and each element is an integer from 0 to 1,000,000,000.
