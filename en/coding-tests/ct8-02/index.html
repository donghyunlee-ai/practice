Follower count ranges

Write code · Medium · §8.1 Searching a sorted list

followers holds the number of followers of each account. The follower counts are in no particular order.

ranges holds the follower ranges that advertisers are looking for. An element [lo, hi] of ranges means the advertiser wants accounts with at least lo and at most hi followers. Complete the function solution, which returns a list of how many such accounts there are for each condition, in the same order as ranges.

Function

solution(followers, ranges)

Constraints

  • The length of followers is from 1 to 500,000, and each element is an integer from 0 to 1,000,000,000.
  • The length of ranges is from 1 to 20,000.
  • Each element of ranges has the form [lo, hi], where lo and hi are integers from 0 to 1,000,000,000 and lo is at most hi.
