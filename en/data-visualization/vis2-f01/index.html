Splitting the work between the Figure and the Axes

Fill in the blanks · Basic · §2.2 How Figure, Axes, and Axis fit together

Draw a line chart of the campus radio station's listeners by time slot and save it to a file. In the five blanks, write the name of the object that receives each command. Commands that change the whole figure go to fig, and commands that change the one chart area where the line is drawn go to ax.

slots = ["7am", "10am", "1pm", "4pm", "7pm", "10pm"]
