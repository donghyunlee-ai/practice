Saving a bar chart of movies by genre at a set pixel size

Write code · Medium · §4.3 Arranging charts and saving results

The DataFrame movies lists the movies that students in a class watched, one movie per row. Use seaborn's countplot() to draw bars showing how many movies there are in each genre. Put the bars in the order Action, Comedy, Drama, and set the x-axis label to Genre and the y-axis label to Movies.

Save the figure as genre_counts.png, with just the file name and no folder. Choose the figure size (figsize) so that the PNG saved with dpi=150 is 900 pixels wide and 600 pixels tall. bbox_inches="tight" trims the margins and changes the number of pixels, so do not use it in this problem.
