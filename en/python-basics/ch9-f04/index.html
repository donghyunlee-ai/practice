The right mode for three files

Fill in the blanks · Medium · §9.4 Syntax that never forgets, and the contract of modes

history.txt gets one new line with the subscriber count each day, and latest.txt keeps only the most recent value. backup.txt is made only once, the first time; if it already exists, the code must stop with an error instead of overwriting it.
