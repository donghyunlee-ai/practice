Printing a summary of new followers

Write code · Medium · §10.3, §10.5, §10.6 Polishing the math helper

Two lists hold, in the same order, the account names and the number of new followers each account got in the last 7 days. For each account, print one line in the form name: count (label). The label is rising if the account got 50 or more new followers, and steady if not. On the last line, print the number of rising accounts, like Rising accounts: 2. Use zip to go through the two lists side by side.

Starter code

names = ["mina", "jun", "sora"]
new_followers = [72, 15, 50]
