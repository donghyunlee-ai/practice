Summarizing a list of posts

Write code · Medium · §7.2, §7.3 Building up

In this list, each post is a dictionary. Find the total number of likes, a list of the authors whose posts have 100 or more likes, and the author with the most likes. Print the results on three lines in the form Total: value, 100 or more: list, and Top author: name. Do not use sum(), max(), sorted(), or sort().

Starter code

posts = [
    {"author": "mina", "likes": 120},
    {"author": "jun", "likes": 80},
    {"author": "sora", "likes": 200},
    {"author": "hana", "likes": 0},
]
