Activity points added separately

Write code · Basic · §6.1 What if

Find a post's activity points and store them in point. The points start at 0. Add 2 points if there are 100 or more likes, and add 3 points if there are 10 or more comments. Check the two conditions separately. If both are met, the post gets 5 points.
