The run order decides the value

Predict the output · Basic · §1.2, §1.3 The bare minimum about notebooks

A notebook has four cells. From the top, we call them cell 1, cell 2, cell 3, and cell 4. You ran them in this order: cell 4, cell 3, cell 1, cell 2, cell 3. The code below joins the cells in the order they ran. Lines that start with # are notes that say which cell each part is, so they do not run. Predict the output of each run, in order.

Code

# Cell 4
likes = 95
# Cell 3
print(likes)
# Cell 1
likes = 70
# Cell 2
print("likes")
# Cell 3 (run again)
print(likes)
