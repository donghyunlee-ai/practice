A new tier hidden by a wider condition

Code review · Medium · §6.3, §6.4 Decided at the boundary

This code adds a new Official tier to the follower tiers. The tiers are Official for 10000 or more followers, Partner for 1000 or more, Growing for 100 or more, and Newcomer for everyone else. The code runs without errors, but an account with 12000 followers comes out as Partner. Fix it so that the tiers follow these rules. Grading runs your code several times with different follower counts.

Code to fix

followers = 12000

if followers >= 1000:
    tier = "Partner"
elif followers >= 10000:
    tier = "Official"
elif followers >= 100:
    tier = "Growing"
else:
    tier = "Newcomer"
print(tier)
