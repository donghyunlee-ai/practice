This code prints the average number of likes per post. Predict the output without running the code.

Code

likes = {"mina": 120, "jun": 30, "sora": 90}
posts = {"mina": 4, "jun": 0, "sora": "3"}
for name in ["mina", "jun", "dami", "sora"]:
    try:
        print(name, likes[name] / posts[name])
    except ZeroDivisionError as e:
        print(name, "failed:", e)
    except KeyError as e:
        print(name, "failed:", e)
print("Done")
