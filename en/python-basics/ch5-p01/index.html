The order of calculation in an engagement score

Predict the output · Basic · §5.2 Order of operations

This code calculates a post's engagement score with three different expressions. Predict the output without running the code.

Code

likes = 20
comments = 4
shares = 3
print(likes + comments * 2 + shares * 3)
print((likes + comments) * 2)
print(likes + comments / 2)
