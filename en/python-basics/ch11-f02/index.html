A cache that remembers tags already counted

Fill in the blanks · Medium · §11.6 The math helper evolves

This class counts how many posts have a given tag. It remembers each tag it has counted in the dictionary cache, and when it is asked about the same tag again, it returns the result right away without scanning the posts. scans counts how many times it has scanned the posts.
