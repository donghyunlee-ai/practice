Updating the follower count and checking the goal

Write code · Medium · §5.3 The language of true and false

Today gained people started following and lost people unfollowed. Change followers to the follower count at the end of today. Then store True in reached if that count is at or above the goal goal, and False if it is not.

Starter code

followers = 480
gained = 35
lost = 12
goal = 500
