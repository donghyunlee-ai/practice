[한국어]
이 저장소와 https://donghyunlee.kr/practice/ 의 문제(지문, 시작 코드, 정답 코드, 힌트, 해설), 목표 그림,
화면 문구, 프로그램 코드(채점기 포함)의 저작권은 이동현에게 있습니다.

자유롭게 할 수 있는 것
- 혼자 공부하며 문제를 푸는 것
- 수업이나 스터디에서 사이트와 문제의 주소(링크)를 나누는 것
- 문제 하나를 출처('파이썬 연습(donghyunlee.kr/practice)')를 밝혀 화면 캡처나 짧은 인용으로 소개하는 것

허락을 받아야 하는 것
- 문제, 해설, 그림을 모아 복제하거나 다른 사이트, 문제은행, 교재, 시험지에 옮겨 싣는 것
- 문제나 코드로 돈을 받는 강의, 책, 앱, 서비스를 만드는 것
- 코드(채점기 포함)를 가져다 다른 사이트나 프로그램을 만드는 것
- 문제와 해설을 인공지능 학습용 데이터로 모으거나 쓰는 것
